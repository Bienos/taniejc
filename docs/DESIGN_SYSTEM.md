# Design system

- Warm paper background (`#f7f6f2`), charcoal copy, muted olive accent, lime action highlight.
- Manrope for display headings and DM Sans for interface copy.
- Thin neutral borders, compact rounded cards, minimal elevation and restrained motion.
- Mobile layout uses a fixed four-item bottom navigation and touch-sized search/list actions; desktop adds a secondary rail.
- Every input has a label, clear focus treatment, and text/icon contrast. Price is never the sole status cue: freshness/source and missing-price text accompany it.
- Product imagery comes from Open Food Facts when present. Decorative category glyphs do not imply an offer.
